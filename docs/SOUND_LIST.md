# 効果音（SE）・BGM リスト

今はすべてゲームの中で合成した音（仮）です。フリー素材に差し替えるときは、下の **ファイル名** で `audio/` フォルダに入れてもらえれば、その音から順に置きかえます（ない音は合成の音のまま）。

## BGM（組みこみ済み：ユーフルカさんの曲 16曲）
- 一覧と使う場面は `data/bgm.txt`。シナリオでは `@BGM 呼び名` で流し、`@BGM なし` で止める
- 何も書かなくても、場面に合わせて自動で切りかわる

| 場面 | 自動で流れる曲（呼び名） |
|---|---|
| タイトル・年表・ずかん・せってい・けっか | 図書館（切れ目なく流れつづける） |
| 話のはじまり | プロローグ＝学校／第1話〜＝町 |
| 調査①／調査②（@ゆがめる より後の調査） | 調査1／調査2 |
| @きざし・@ゆがめる（ユガミ登場） | 神殿 |
| 議論（さいごの証言だけ） | 証言（最後の証言） |
| @もどす | 封印 |
| 論破バトル | バトル |
| @退場・@旅立ち | 止める（フェードアウト） |
| まとめ | 日常 |
| 記憶のかけら | 一方 |

- 自動の曲を変えたいときは、その場面の **すぐ前** に `@BGM 呼び名` を書く（間に @背景・@画像 があってもよい）
- 今の使い分け：身分の高い人との会話＝王国、第2話のお忍び＝潜入、別れの場面＝想い、母にまつわる切ない記憶のかけら（第3・4話）＝オルゴール
- 音の作り直し：素材のフォルダを指定して `python3 tools/make_bgm.py フォルダ`（モノラル・Opus 18kbps。16曲で約4MB）。音のファイル（audio/）はリポジトリに入れない

## 効果音（SE）
- 素材の音（効果音ラボ）を使っているものと、場面は `data/se.txt`。一覧にない音は、今までどおりゲームの中で合成した音が鳴る
- シナリオでは `@SE 呼び名` で鳴らせる（例：`@SE sparrow` 次の朝、`@SE gate` 門、`@SE run` 走る）
- 文字送りの「ぽぽぽ」は合成の音のまま

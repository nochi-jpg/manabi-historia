# 効果音（SE）・BGM リスト

今はすべてゲームの中で合成した音（仮）です。フリー素材に差し替えるときは、下の **ファイル名** で `audio/` フォルダに入れてもらえれば、その音から順に置きかえます（ない音は合成の音のまま）。

## 容量の目安（1ファイル10MB以内にするため）
- 今の index.html は約1.7MB。音に使えるのは **合計6MBくらいまで**
- BGM：mp3・モノラル・96kbps・**1曲30〜60秒のループ**にすると、1曲0.4〜0.7MBくらい
- SE：1つ数十KB（短いものを選ぶ）

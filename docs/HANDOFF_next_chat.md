## 3. 作業の流れ（毎回これ）
```
cd manabi-historia
（台本・コードを直す）
python3 build.py                         # index.html を作る。⚠ が出たら直す（2行こえ・ふりがな辞書にない漢字）
python3 tools/yomi_missing.py            # ふりがなが足りない漢字の一覧（必要なら data/yomi.txt に足す）
node tools/test/play3.js "$PWD/index.html" 1   # 第1話を自動で通しプレイ（1〜4）。RUBY_OVERFLOW [] と ERR [] ならOK
git add -A && git commit -m "日本語で何を直したか" && git push
```
- テストは playwright を使う。/opt/pw-browsers の Chromium（chromium-1194）に合う版を入れる：`mkdir -p /tmp/pw && cd /tmp/pw && npm i playwright@1.56.1`、実行は `NODE_PATH=/tmp/pw/node_modules PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers node tools/test/play3.js "$PWD/index.html" 5`（新しい版だとブラウザが見つからない）。
- push するには、add_repo を access:"push" で呼び、`/home/claude/manabi-historia` に clone しなおす。スクショの保存先は環境変数 `SHOT`（ふだんは /tmp/）
- tools/test のほかのテスト：`trans.js`（場面の切りかわりのチラつき検査）、`uiaudit.js`（UIのはみ出し）、`skiptest.js`（既読スキップ）、`near.js`（おしいカード）、`bgmprobe.js`（BGMの切りかわり）、`play2.js`
- コミットメッセージは**日本語・何を直したか一文**（例：「第3話：ほら貝→太鼓（時代に合わせる）」）
- **トークン節約のため、直しはまとめて1回で push**（2026-10-18 先生と決定。→ 13章）
- 先生は push のたびに GitHub Pages で確認する。返事の最後に「1〜2分で反映されます」

### 注意（ハマりどころ）
- `audio/`（BGM・効果音）と `art/sil_*.webp`（モブ影絵）は**再配布できない素材なのでリポジトリに入っていない**。
  → `build.py` は、手元にないときは**今の index.html に埋めこまれている音・影絵を引きつぐ**ようにしてある（2026-10-18）。だから新しいチャットでも、そのまま `python3 build.py` してよい。**index.html を消さないこと**
  - 音を作り直すときだけ、先生に素材zipをもらって `tools/make_bgm.py` / `tools/make_se.py` を使う
- `pgrep -f` / `pkill -f` は自分のシェルにも当たるので使わない
- Playwright で `p.evaluate(() => playEpisode())` は話が終わるまで待ってしまう → `() => { playEpisode() }` と波かっこで包む
- ウィキメディア・コモンズは 429（アクセス制限）になりやすい。User-Agent をつけ、30秒待ってやり直す。画像の幅は 500px のサムネイルを使う

## 5. 台本の書き方（要点）
くわしくは `SCRIPT_GUIDE.md`。このチャットで足した命令：
| 命令 | 意味 |
|---|---|
| `@BGM 呼び名` | 曲を切りかえる（ふだんは場面に合わせて自動。`@BGM なし` で止める） |
| `@SE 呼び名 回数` | 効果音。`@SE taiko 3` で 1.9秒ごとに3回 |
| `@スタッフロール 曲` | エンディングのスタッフロール |
| `@変装 名前 look` | 顔を art/名前_look.webp にかえる（卑弥呼のお忍び `@変装 卑弥呼 hood`）。`@変装 名前` でもどす |
| `@たいせつ key \| 名前 \| 説明` | ずかんの「たいせつ」タブに出るおくりもの（台本の先頭に書く） |
| `@画像 key` | 中央に絵を出す（おくりものなど）。`@画像` で消す |
| `@時ワープ 643 645 飛鳥 夕焼け` | **同じ話の中で時が進むときは必ずこれ**。トケイ登場 → 針が回る・年と季節（春夏秋冬）のカウント・空の色が朝昼夕夜とめぐる（だんだん速く）→ 止まる → 無音 → ブラックアウト → 新しい背景（色つき）で明ける →「645年 2年後」。BGMは自動で「封印」→無音。あとに `@BGM`・`@SE`（sparrow・kansei・walk など）を書く |
| `@背景 飛鳥 夕焼け` | 背景に時間帯の色をつける（朝／夕焼け／夜）。色なしでふつう |
| `@人物 ？？？ 人:おとこ R shoumu` | 4つめで顔グラを指定（名のる前の人物に） |
| 議論の矛盾行の6つめ | **おしいカード**：`カード名＝本じいのセリフ／セリフ`。♡をへらさず本じいがヒント。複数は「；」 |
| 調査アイコン | ふつうは手に入るカードの写真。`写真:カード名`／`画:artの呼び名`／`絵:絵文字`（絵文字は最後の手段） |

### 1話の流れ（型）
1. タイムスリップ（最初の `@背景` は最初のセリフより前に書く）
2. 重要人物と出会い、仲良くなる（ここを**長めに**。絆をつくる）
3. 調査パート①：重要人物の案内でカード6枚前後
4. ゆがみはじめ：ユガミ登場、重要人物を「特異点」と呼び、認識をゆがめる（`@ゆがめる`）
5. 調査パート②：ゆがみきる前にかけまわってカード6枚前後
6. 議論（証言パート）：3パート × 4つの証言。矛盾にカードをつきつける → `@もどす`
7. 論破バトル：ユガミのウソをカードで正す（ただし画面の言葉は「矛盾発見」）
8. まとめ（空らんうめ）→ エンディング（おくりもの）→ 記憶のかけら（一方そのころ）
- カードは1話12枚。話が進むほど証言・カードを増やして難しくしてよい

### カードと証言のルール（ずれを防ぐ）
1. ウソは、**決め手の一文をもつカード1枚とだけ**矛盾させる
2. 「ふつう」「ホント」の文は、どのカードとも矛盾させない（子どもが別のカードをつきつけたくならないか）
3. まとめの空らんは、ほかのカードを入れると文が通らないように
4. カードの説明は、決め手の一文が1枚にしかないように書き分ける
5. 議論の分かれる物（例：縄文の田んぼ）はまちがいにしない。時代がはっきりちがう物だけ
6. ちょっと矛盾して見えるカードがあるときは「おしいカード」にする（例：第3話のワカタケルの手紙）

### 証言の書き方（先生の指定）
- 証言は「歴史の説明」ではなく、**ゆがめられた人物の、ゆがんだ気持ち**が見えるように書く（例：太子「海の 向こうの 国にも、学ぶ ことなど 何も ない」）
- ※「調査」ではなく「証言パート」の話。言葉を取りちがえない

## 6. 文体のルール（台本）
### 表記
- **ひらがな多め、文節ごとに半角スペース**で区切る：`ここは 600年ごろの 斑鳩《いかるが》。今の 奈良県じゃな`
- 漢字は data/yomi.txt で自動ふりがな。特別な読みは `漢字《よみ》`
- 大事な言葉は `【 】` で色をかえる
- `＊` で始まる行はナレーション。`＊――光が おさまると、…` のように「――」で場面転換
- `（ ）` つきのセリフは心の声（ユガミのひとりごと「（……そうだ。ゆがみの 力を 集めれば、オレの 願いは かなう）」など）
- 1吹き出し2行まで（だいたい37字×2）。こえたら build.py が警告
- エンジンが助詞のあとで改行しやすくしている（`phr()`）。変なところで折れたら言葉を短くする

### 時代考証（先生がとても気にしている）
- その時代の人は、**まだない物・言葉・考え方を知らない**（先生：「言葉が通じるのはいいが、存在しないものを知っているのは変」）
  - 直した例：縄文の「本」→「四角いもの」、「スープ」→「にこみ」、古代の人の「中国」→「大陸」「魏」「宋」、「摩訶不思議」→「ふしぎ」、古墳時代の「ほら貝」→「太鼓」
  - 重要人物に「埼玉」「熊本」と言わせない → 本じいが「（こっそり…）」と小声で補足
- 今の地名・国名は**本じい**が補足（ユウキではなく本じい。例：「魏は、そのころ 今の 中国に あった 国じゃ」）
- 年代の順番に注意（例：米づくりの伝来は魏の時代より前。卑弥呼が「魏から米が来た」ようなことを言わない）
- 先生がOKを出した言い方は変えない（例：「なんとも ふしぎな 身なり」）

### 名前の出し方（前後の矛盾）
- まだ名のっていない名前で呼ばない
  - ユガミ：プロローグで**本人が名のる**
  - トケイ：第1話で**ユウキが名づける**
  - 「特異点」：ユガミが言うまで使わない。ユウキたちは第1話の後半から
- 旅の間、ユウキは全員から「ユウキ」と呼ばれる。**ユガミの前で「遥」を出さない**
- ユウキの性別がわかる言葉（彼・男の子・女の子）を使わない

**このファイルだけ読めば、まなバト側の作業ができる**ように書いています。

## 1. 何をするのか
- まなびヒストリア（小6社会・日本史の学習ゲーム）は、各話を**★5でクリアしたときだけ**「あいことば」を表示する。
- 子どもは、そのあいことばを**まなバトに入力**して報酬をもらう。
- 報酬は、**1つのあいことばにつき1回だけ**受け取れる。
- これまでは、先生がデバッグモードで手動でコインを足していた。これをやめて、あいことばで自動化する。

## 3. まなバトに作ってほしいもの
### 入力画面
- メニューに「あいことば」ボタンを置き、入力欄＋「けってい」の画面を出す。
- UIのルール：ボタン・文字・枠の高さや大きさをそろえる。スクロールバーは使わない。

### 入力の正規化（ヒストリアと同じ）
1. 前後の空白を取り、途中の空白もすべて消す。
2. 「・」「･」を消す。
3. カタカナをひらがなに変える。

### 照合
- コードに平文のあいことばを書かず、**ハッシュで照合する**。まなバトのリポジトリは公開なので、ソースを見ても答えがわからないようにするため。
- ハッシュ関数（上の表の値は、これで計算した）：

```js
function akHash(s) {
  let x = 2166136261;
  for (const ch of "aikotoba:" + s) { x ^= ch.codePointAt(0); x = Math.imul(x, 16777619) >>> 0; }
  return x.toString(36);
}
const normAk = s => (s || "").replace(/\s+/g, "").replace(/[・･]/g, "")
  .replace(/[ァ-ヶ]/g, c => String.fromCharCode(c.charCodeAt(0) - 0x60));
// 表のハッシュを、話の順に配列でもつ
const AK_HASHES = ["1itsqa1","nlryes","fn2z8o","1vi8tv7","1j47w91","q3yldu","9nvii3","tloul8","1iq9jxo","8extv1",
  "y3xcxj","19eye1j","bcxv","5l9rl1","1n4ca3m","gd5jlh","1ap8mgw","pxy3ag","1o0e34o","4l3yw6","1yehjlf","1jjc7va"];
const epNo = AK_HASHES.indexOf(akHash(normAk(input))) + 1;   // 0なら不正解
```

### 1回だけ受け取れるしくみ
- 受け取った話の番号を、セーブデータに記録する（例：`ak: [1,2,5]`）。
- **QRのセーブ出力にも、この記録を入れる**。入れないと、QRから復元するたびに報酬をもう一度もらえてしまう。
- 入力したときの表示：

| 入力 | 表示 |
|---|---|
| 正しくて、はじめて | 報酬の演出（例：「第5話 大化の改新 の あいことば！ 〇〇コイン ゲット！」） |
| 正しいが、受け取りずみ | 「この あいことばは もう つかったよ」 |
| まちがい | 「あいことばが ちがうみたい」 |

### 報酬（要決定：のち先生と相談）
- 案：第1〜20話は同じコイン量にする。第21話は多め。第22話は特別な報酬（限定アイテム・称号など）。
- 決まったら、このファイルに書き足す。

## 4. ヒストリア側のしくみ（参考）
- **ヒストリアは単独で遊ぶゲーム。ゲームの中には、まなバトのことを一切書かない**（「まなバトで使える」などの表示もしない）。連携は、あくまでおまけ。子どもには先生が口頭で伝える。
- セーブは、基本はブラウザ（localStorage）。
- ★5でクリアしたときだけ、結果画面にあいことばを出す。
- ヒストリアであいことばを入れると、その話が「★5クリア」に戻る。タブレットが壊れたら、先生が★5の話の数だけあいことばを教えて、入れてもらう。
- **かいほうの じゅもん**（先生が授業の進度に合わせて配る、話を開ける言葉）は、あいことばとは別のもの。まなバトでは使わない。
- あいことば方式に合わせて、ヒストリアの今の「ふっかつの じゅもん」（16文字）は、あいことば方式に置きかえる予定。

## 5. 注意
- あいことばは歴史に関係する言葉なので、子ども同士で教え合える。報酬は「1台につき1回」なので、教えてもらった子も受け取れてしまう。この扱いは、のち先生に確認中。
- まなバトのUI素材は再配布できないので、ヒストリアの公開リポジトリには入れない（逆方向のコピーもしない）。

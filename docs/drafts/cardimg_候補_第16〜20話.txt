## 要確認（あやしい・重複など）
# 勝海舟: Commons の古写真（PD）。若いころの有名な写真。
# 薩長同盟: 坂本龍馬の裏書（朱書き）。所蔵は宮内庁、画像は人事院の資料で CC BY 4.0。文字だけなので子どもには地味。
# 学問のすゝめ と ggakumon、ノルマントン号事件 と gnormanton、防空ずきん と gzukin は同じ画像（おくりもの自体が同じ物なので）。カード側だけ「描く」にする案もあり。
# 日清戦争: ビゴー「魚釣り遊び」（1887年。戦争の7年前の風刺画だが、教科書で日清戦争の説明によく使われる絵）。
# 国民学校: 1944年の野外授業の写真（中村立行）。国民学校そのものの写真ではない。Commons では PD-Japan-oldphoto（日本の古い写真）扱い。
# 学童疎開: 寺の宿舎の子ども（1944年、中村立行）。暗めの写真。
# 勤労動員: 東京の工場ではたらく女子挺身隊の写真（作者不明、PD）。写真が暗く、見て分かりにくい。
# gkagi: ColBase の琉球の錠と鍵（19世紀）。「外務省の古い鍵」とは別物。描く案もあり。
# gkenpouhanashi: 『あたらしい憲法のはなし』の三原則のさし絵（元画像が 327px と小さい）。表紙の公開画像は見つからなかった。
# 原子爆弾: 原爆ドームの今の写真（CC BY 2.5。GFDL / CC BY-SA 3.0 とのマルチライセンスから選んだ）。被害の写真は避けた。
# 空襲: 富士山の上を飛ぶ B-29 の写真（米軍撮影、PD）。被害の写真は避けた。
# CC BY-SA の画像: 日米和親条約・日米修好通商条約・不平等条約・ポーツマス条約（World Imaging 撮影の外交史料館展示）、大日本帝国憲法（CC BY-SA 4.0）、学制（旧開智学校）。表示（と継承）が必要。
# 東京オリンピック: Commons に1964年開会式の写真（Keystone、「PD」扱い）はあるが根拠があいまいなので「描く」にした。

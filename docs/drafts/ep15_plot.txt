■ きほん
1. 単元：2-8 町人の 文化と 新しい 学問。重要人物：杉田玄白（前野良沢も 登場）
2. あいことば「かいたいしんしょのよあけ」→ 4年 かけた 本が できあがる 朝
3. 舞台：1771年 春 江戸（オランダの 解剖書を 読みはじめる 夜）→ @時ワープ 1771 1774 → 1774年 江戸（解体新書が 出る 年）
   - はじまりの演出：1641年 → 1771年へ 順まわし
4. この話の 心
   - 辞書も ない オランダ語の 本を、何年も かけて 少しずつ 読んだ。「眉（まゆ）とは 目の 上に 生えた 毛なり」の 一文に 一日 かかった
   - ユウキ「社会の 教科書 読むのも たいへんなのに……」→ 玄白「わからぬ ことは はずかしくない。わからぬ まま に する のが はずかしいのだ」
   - 本じい（教科書）が いちばん 感動する 話（「書物は 読まれてこそ じゃ……」）

■ 時代考証で気をつけること
5. 腑分け（解剖）の 見学は 1771年 小塚原（処刑された 人の 体）→ 子ども向けに 場面は 見せない。「体の 中を 見せてもらった。本の 絵と そっくりだった」と 玄白が 語る だけ
6. 「蘭学」は この ころから 使われた 言葉。「ターヘル・アナトミア」は 玄白たちの 呼び名 → そのまま 使える
7. 前野良沢は 名前を 本に のせるのを ことわった → 良沢の 気持ちを 一場面で
8. 本居宣長は 伊勢松坂の 医者で 古事記を 研究中（古事記伝が 出るのは のち）→ 松坂から 来た 薬売りが「松坂に 古事記を 読みとく お医者が いる」と 話す
9. 近松門左衛門は 1724年に 亡くなっている → 人形浄瑠璃・歌舞伎の 小屋で「近松の 作だ」と 話す（演目は 国性爺合戦など）
10. 伊能忠敬は 1774年は まだ 佐原の 商人（地図を 作るのは 1800年から）→ 出すか どうか（A）
11. 浮世絵は この ころ 多色ずりの 錦絵が 生まれた ころ。歌川広重・葛飾北斎は まだ 若い／生まれていない → 名前を 出さず「浮世絵」だけ

■ 流れ
12. 時ワープ（1641 → 1771）→ 1771年 春 夜、玄白の 部屋
   - 本の 山の 中に ユウキが 落ちてくる。玄白「なんじゃ、オランダの 本から 子どもが 出てきた！？」
13. 絆（長め）
   - 玄白・良沢・淳庵が「ターヘル・アナトミア」を かこむ。一文字ずつ 指で たどる
   - ユウキも 本じいも 手伝う（本じい「わしは 日本語の 書物じゃから……」）→ 上の「眉の 一文」の 場面
   - 玄白が 小塚原で 見たことを 静かに 語る（5）
14. 調査①（玄白の 部屋と まわり・6枚）
   - 杉田玄白／前野良沢／ターヘル・アナトミア（オランダの 本）／蘭学（淳庵）／出島から 来た 本の 話 → 長崎の 通訳（通詞）「オランダ語を 話せる 人は 長崎に しか いない」→ カード「オランダ語」／江戸の町人（にぎやかな 町）
15. 時ワープ 1771 → 1774（朝）… 本屋の 前に「解体新書」の はり紙
16. ゆがみはじめ
   - 本が できあがった 朝、ユガミが 来る（第14話の 記憶のかけらの あと。ユガミの 声に 元気が ない）
   - ゆがんだ 玄白：「外国の 学問など 役に 立たぬ」「本など 燃やしてしまえ」「わからぬ ものは わからぬ まま で よい」
   - 解体新書の 文字が 紫に にじんで 消えていく 演出
17. 調査②（江戸の 町を かけまわる・6枚）
   - 解体新書（本屋）／寺子屋（先生と 子ども）／歌舞伎（芝居見物の 町人）／近松門左衛門（人形浄瑠璃の 小屋）／浮世絵（売る 人）／本居宣長（薬売り）
18. 議論（3パート × 4証言）
   - パート1「オランダの 本」：ターヘル・アナトミア・オランダ語・蘭学 から 1つ
   - パート2「本が できるまで」：杉田玄白・前野良沢・解体新書 から 1つ
   - パート3「町人の 学びと 楽しみ」（最後の証言）：寺子屋・歌舞伎・本居宣長 から 1つ
19. 論破バトル（ユガミ）
   - ウソの例：「町人の 子は 字を 習えなかった」→ 寺子屋／「解体新書は 中国の 本を 写した」→ ターヘル・アナトミア／「日本の 古い 書物を 調べた 人は いない」→ 本居宣長
20. まとめ（空らん）
   - 例：「杉田玄白と［前野良沢］は、オランダ語の 医学書を 4年 かけて 訳し、［解体新書］を 出した。これを きっかけに［蘭学］が さかんに なった」
21. エンディング
   - 本屋の 前、朝日。玄白「夜明けは 来る。わからぬ ことに 向きあえば」（あいことば「かいたいしんしょのよあけ」）
   - おくりもの（C）
   - （A で ① の ときだけ）時ワープ 1774 → 1800 の エピローグ：年老いた 玄白が、蝦夷へ 地図を 作りに 行く 伊能忠敬を 見おくる
22. 記憶のかけら「レキシクイとの 出会い」
   - 厄災の あと。がれきの 中で ひざを かかえる 彼方。手には 母の 銀の 時計
   - 紫の 光。小さな うなぎのような もの（小さな レキシクイ）が 彼方の 手に すりよる
   - 彼方「……おまえも、ひとりなの？」→ 頭に 声のない 思念が ひびく（文字で）：「歴史を 書きかえれば、取りもどせる」
   - 本じい の 一言説明 は なし（プレイヤーだけが 知る）。レキシクイは 声を 出さない
